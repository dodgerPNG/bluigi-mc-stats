# spooky-bloogui server stats

Live stats for our Minecraft server: who's online, leaderboards, fun facts and the Cave Dweller score.

**Page:** https://dodgerpng.github.io/bluigi-mc-stats/

The numbers come from the server's dashboard, which uploads `status.json` to the `data` branch every 5 minutes while it runs. Typed chat and coordinates are left out on purpose.
